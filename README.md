Строки подпиши в самой таблице. 6) Заполни пропуски в равенствах. Сгенерируй 21 пример с пропусками множителей или делимого/делителя. Таблица 3 столбца по 7 примеров. ## Окружающий мир

```
Составь 2 самостоятельных варианта проверочной работы по окружающему миру для 3-го класса на тему «Тела, вещества и частицы».

Создай два отдельных Markdown-файла:
- «Окр - тела. Проверочная работа 1.md»
- «Окр - тела. Проверочная работа 2.md»

В каждом файле используй заголовок «Проверочная работа по окружающему миру», укажи тему и номер варианта, класс («3-й класс»), затем в одной строке добавь поля «Имя и фамилия» и «Дата» с линиями для заполнения. Разделы оформи заголовками второго уровня и пронумеруй от 1 до 7.

Проверь, чтобы оба варианта охватывали понятия тела, вещества и частиц; различение тел и веществ; три состояния вещества; свойства твёрдых тел, жидкостей и газов. Используй разнообразные задания, например выбор определения или слов, вставку пропусков, распределение примеров по группам, сопоставление, заполнение таблицы, поиск ошибок, отметку верных утверждений и объяснение наблюдения или явления. Сформулируй задания по-разному в двух вариантах, сохраняя сопоставимую сложность и охват темы. Следи за научной точностью и подходящим для третьего класса языком.

После задания 4 добавь разрыв страницы перед заданием 5 с помощью HTML-тегов `<br>` в отдельных строках; перед ним можно оставить комментарий `<!-- new lines as page breaks -->`. Для развёрнутых ответов оставь несколько строк для записи. Используй Markdown-таблицы и чекбоксы `- [ ]`, где это уместно. Не добавляй ответы или ключи. Выведи полный текст каждого файла отдельно.
```
