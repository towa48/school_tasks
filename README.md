## Как создать md файлы
Для создания нужен доступ к ИИ модели, например, ChatGPT. Вводите промт и получаете ответ в markdown формате. Если подписки платные, то модель может сразу генерировать файлы. Например, VS Code + GitHub Copilot.

## Как сгенерировать PDF из md
Ставить node надо только чтобы получить pdf из md файлов.

1. Установить nodejs https://nodejs.org/en
1. в консоли `npm i`
1. в консоли `npm run export:pdf`
1. Найти файлы pdf в папке export

Экспортировать можно всего несколько файлов, список сортируется по дате последнего изменения.
```
$ npm run export:pdf 2
```
